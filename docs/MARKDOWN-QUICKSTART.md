# Markdown quickstart

Markdown is plain text with lightweight formatting. GitHub renders it when displaying `.md` files.

````markdown
# Heading 1
## Heading 2

This is **bold** and this is *italic*.

- First item
- Second item

[GitHub Docs](https://docs.github.com)

`inline code`

```bash
git status
```

> A blockquote

| Name | Role |
|---|---|
| Ada | Developer |
````

## README versus profile README

- A repository `README.md` explains that particular project. GitHub displays it on the repository page.
- A **profile README** appears on your GitHub profile. To create one, create a public repository whose name exactly matches your GitHub username and put a non-empty `README.md` in the repository root.

Do not confuse the exercise's `PROFILE.md` file with the special profile README repository. `PROFILE.md` is simply a file used to practise Markdown and commits in this exercise.
