# Contributing to this learning exercise

This repository is a reusable workshop template. Participants should create their own copy using **Use this template** and complete the four missions in that copy.

Please do not submit your exercise answers to the original template repository. Use the optional real-world challenge in [`COMMUNITY-CHALLENGE.md`](COMMUNITY-CHALLENGE.md) for a contribution to the GDGoC community project.

## Maintainer notes

- Keep mission filenames and branch names in sync with the GitHub Actions workflows.
- Test the complete exercise from a fresh repository created using the template before each workshop.
- Keep workflow permissions limited to the operations needed by each workflow.
- Do not ask participants to publish passwords, access tokens, private keys, phone numbers, or other sensitive information in Markdown files.
